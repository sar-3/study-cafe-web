# STUDY CAFÉ

Školský projekt z webdizajnu (Blok 11) predstavuje STUDY CAFÉ, študentskú kaviareň pre stredoškolákov a vysokoškolákov. Web návštevníkom približuje priestor, ponuku a kontaktné informácie a umožňuje vyskúšať ukážkový rezervačný formulár.

## Sekcie webu

- **Domov** – predstavenie kaviarne, jej vybavenia a študijných zón, otváracie hodiny a odkaz na rezerváciu.
- **Rezervácie** – formulár na výber dátumu, času, počtu osôb a typu stola, s kontaktnými údajmi návštevníka.
- **Ponuka** – káva, nealkoholické nápoje, jedlá a dezerty s ilustračnými cenami a ukážkovou študentskou zľavou s ISIC.
- **O kaviarni a kontakt** – informácie o prostredí, vybavení, otváracích hodinách a kontaktné údaje.

## Funkcie

Navigácia a tlačidlá prepájajú jednotlivé sekcie stránky. Rezervačný formulár kontroluje povinné polia a formát e-mailovej adresy. Po odoslaní zobrazí informáciu, že ide iba o ukážku; údaje sa nikam neposielajú ani neukladajú a rezervácia sa nevytvorí.

## Technológie a zobrazenie

Web je vytvorený pomocou HTML, CSS a JavaScriptu bez frameworkov. Responzívny dizajn prispôsobuje rozloženie širokým obrazovkám aj mobilným zariadeniam.
